## 1. 모바일 조작 안정화

목표: Android 폰에서 키보드 없이 하단 조이스틱만으로 이동이 자연스럽게 동작한다.

구현 범위:
- 하단 조이스틱 영역에서 시작한 터치만 이동 입력으로 인정
- 레벨업/게임오버/광고 UI 중에는 이동 입력 무시
- UI 버튼 터치와 이동 터치가 서로 간섭하지 않도록 유지

성공 기준:
- 화면 아무 곳을 눌러도 캐릭터가 움직이지 않는다.
- 하단 조이스틱을 드래그하면 해당 방향으로만 이동한다.
- 레벨업 선택 중 조이스틱 입력이 남아 캐릭터가 움직이지 않는다.

검증 방법:
- Web 터치 이벤트 캡처
- Android 실기기 터치 테스트

실패 시 수정 방향:
- 조이스틱 시작 반경, 위치, 입력 우선순위 조정

## 2. 전투/보스 안정화

목표: 일반 적, 엘리트, 보스가 잘리지 않고 난전에서도 판독 가능하게 보인다.

구현 범위:
- 보스 스프라이트 안전 프레임 사용
- 새 보스 이미지가 오면 `tools/normalize_sprite_sheets.ps1`로 재정규화
- 보스 HP바, 크기, 충돌 반경 재검토

성공 기준:
- 보스 프레임에 옆 프레임 잔상이나 잘림이 없다.
- 보스가 화면에 등장했을 때 크기와 충돌감이 과하지 않다.

검증 방법:
- 프레임 셀 단위 확인
- 150초 이후 보스 스폰 캡처
- Android 실기기 5분 런 3회

실패 시 수정 방향:
- 보스 전용 새 스프라이트 시트 재생성 또는 프레임 시퀀스 재선정

## 3. 광고/IAP 실기기 검증

목표: 광고와 결제가 게임 흐름을 막지 않고 실패 상황도 안전하게 처리된다.

구현 범위:
- 보상형 광고 6종 확인
- 런 종료 5회당 전면 광고 확인
- 광고 제거 상품 적용 확인
- 일회성 상품 5종, 월간 패스 조회/구매/복원 확인

성공 기준:
- 광고 실패 시 게임 진행이 막히지 않는다.
- 보상형 광고 완료 후 보상이 한 번만 지급된다.
- 광고 제거 구매 후 선택형 보상 광고 외 강제/전면 광고가 차단된다.

검증 방법:
- 내부 테스트 트랙 설치
- 테스트 계정 결제
- 네트워크 끊김/광고 로드 실패 재현

실패 시 수정 방향:
- 광고 요청 상태머신과 구매 복원 로직 보강

## 4. 밸런스 1차

목표: 초반 5분 런이 지루하지 않고, 특정 무기만 강제되지 않게 한다.

구현 범위:
- 코멧 미사일 DPS와 폭발 반경 조정
- 경험치 요구량, 젬 흡수 반경, 적 스폰 밀도 조정
- 영구 강화 비용과 광고 보상량 점검

성공 기준:
- 1~2분 안에 첫 레벨업이 안정적으로 발생한다.
- 미사일이 강력하지만 다른 무기 선택지를 완전히 밀어내지 않는다.
- 무료 유저도 3~5판 안에 영구 강화 체감을 얻는다.

검증 방법:
- 5분 런 5회 수동 플레이
- 레벨/킬/사망 시간 기록

실패 시 수정 방향:
- 무기 피해량, 쿨타임, 적 체력, 경험치 곡선을 조정

## 5. 이미지 추가 적용 대기

목표: 새로 전달될 이미지로 출시용 비주얼을 교체한다.

대기 중인 이미지:
- 로비 UI 9-slice 버튼/패널
- 코멧 미사일/폭발/파편 시트
- 보스 전용 새 애니메이션 시트
- 스토어 등록 그래픽

적용 순서:
1. 원본 이미지 확인
2. 투명도/프레임 경계 검사
3. `assets/images` 또는 `assets/images/normalized` 반영
4. Web 캡처 검증
5. Android AAB 재빌드

## 6. Google Play 내부 테스트 준비

목표: 내부 테스트 트랙에 올릴 수 있는 새 AAB를 만든다.

구현 범위:
- versionCode 증가
- 최신 Web/Android 리소스 반영
- 개인정보처리방침 URL 유지
- 데이터 보안, 광고 포함, IAP 상품 정보 확인
- 내부 테스트 릴리스 노트 작성

성공 기준:
- AAB 업로드 가능
- Play Console 오류 0개
- 내부 테스트 계정에서 설치 가능

검증 방법:
- `godot --headless --path . --quit`
- Web export + Playwright 캡처
- Android release bundle 생성
- Play Console 내부 테스트 업로드

실패 시 수정 방향:
- Play Console 오류 기준으로 manifest, target SDK, billing/ad 설정 수정
