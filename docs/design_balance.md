# Core Survivor: Cosmic Purge - Design & Balance MVP

문서 소유: Game Designer + Game Design Lead + Balance Team  
대상 프로젝트: Godot 4.3 Android 2D  
작성 기준: 개인 개발자 MVP, Google Play Android 전용, 5분 수직 슬라이스 우선  
편집 범위: 본 문서는 `docs/design_balance.md`만 다룬다.

## 0. 문서 원칙

- MVP는 "짧은 5분 런 1개를 재미있게 완주할 수 있는가"를 1차 성공 기준으로 둔다.
- 모든 수치는 구현 검증을 위한 초안이다. 실제 수치는 Godot 빌드에서 프레임, 터치 조작감, 몬스터 밀도, 가독성 확인 후 조정한다.
- 경제 모델은 과도하게 세분화하지 않는다. 영구 성장 비용은 등급형 비용만 정의하고, 장기 LTV/라이브 밸런스는 보류한다.
- 플레이어 입력은 이동만 기본으로 한다. 공격, 타겟팅, 드론 발사는 자동이다.
- 화면 가독성을 위해 적, 탄환, 경험치 오브, 위험 장판, 보스 경고 이펙트는 색상과 실루엣을 명확히 분리한다.

| 발견된 문제 | survivor-like 장르 특성상 무기와 적 밀도가 빠르게 과밀해질 수 있다. |
| 수정 지시 | 5분 수직 슬라이스에서는 탄막보다 읽기 쉬운 밀도와 넓은 회피 공간을 우선한다. |
| 성공 기준 | 첫 30초 안에 자동 공격과 오브 흡수의 재미가 전달되고, 5분 안에 최소 1회 진화와 1회 보스전을 경험한다. |
| 검증 방법 | 실제 기기에서 5분 플레이 후 평균 레벨 8~10, 진화 1~2개, 보스 TTK 35~55초를 확인한다. |
| 승인 상태 | 초안 완료 |

핵심 루프:

1. 플레이어가 가상 조이스틱으로 이동한다.
2. 코어와 장착 무기가 자동으로 가장 가까운 적 또는 우선 타겟을 공격한다.
3. 적 처치 시 오염 에너지 오브와 낮은 확률의 회복/자석 아이템이 드롭된다.
4. 오브 흡수로 레벨업하면 3개 선택지 중 하나를 고른다.
5. 무기 레벨, 드론 레벨, 패시브 성장이 누적된다.
6. 특정 무기 레벨과 드론 조건을 만족하면 진화 무기로 전환한다.
7. 엘리트와 보스가 런의 압박을 만든다.
8. 사망 또는 클리어 후 정화 코어 파편을 얻고 영구 업그레이드에 사용한다.
9. 강화된 상태로 재도전한다.

## 5. 레벨업 선택지 설계

| 선택지 유형 | 등장 조건 | 예시 | 비고 |
|---|---|---|---|
| 신규 무기 | 빈 무기 슬롯 있음 | 이온 블래스터 획득 | 최대 4개 |
| 무기 강화 | 보유 무기 Lv.5 미만 | 피해 +20%, 쿨다운 -8% | 무기별 고정 성장 |
| 신규 드론 | 빈 드론 슬롯 있음 | 실드 드론 획득 | 최대 2개 |
| 드론 강화 | 보유 드론 Lv.3 미만 | 효과 강화 | 진화 조건과 연결 |
| 회복 선택 | HP 60% 이하일 때 가중치 증가 | 즉시 HP 25 회복 | 실패 완화 |
| 보상 선택 | 낮은 확률 | 정화 파편 소량 획득 | 런 내 전투력보다 낮은 우선순위 |

레어도는 일반/희귀/에픽 3단계만 사용한다. MVP에서는 선택지 풀을 단순하게 유지하고, 무기별 세부 업그레이드 분기는 만들지 않는다.

## 6. UI/UX 밸런스 기준

| 화면 | 기준 |
|---|---|
| 전투 HUD | HP, 레벨, 경험치 바, 남은 시간, 보스 HP만 상시 표시 |
| 레벨업 팝업 | 카드 3장, 카드당 이름/아이콘/효과 1줄 |
| 결과 화면 | 처치 수, 생존 시간, 획득 파편, 광고 2배 버튼 |
| 상점 화면 | 영구 업그레이드 10종을 스크롤 목록으로 표시 |
| 광고 버튼 | 보상과 제한을 버튼 근처에 명확히 표시 |
| IAP 화면 | 전투력 상품과 코스메틱 상품을 구분 표시 |

모바일 가독성 기준:

- 플레이어와 보스는 일반 적보다 채도와 외곽선을 강하게 둔다.
- 경험치 오브는 청록색, 회복은 초록색, 위험 장판은 붉은색, 진화 촉매는 금색으로 고정한다.
- 일반 적은 작은 SD 실루엣, 엘리트는 크기 1.8배, 보스는 3.0배 이상으로 구분한다.
- 화면 흔들림은 보스 피격/진화 순간에만 짧게 사용한다.
