# 메인 화면 흐름 정리

## 단계: 오프닝 화면 -> 로비 화면 -> 게임 화면

* 담당 에이전트: Command Agent / PM, Game Designer, Dev Agent B
* 목표: 앱 실행 즉시 전투에 들어가지 않고, 출시형 모바일 게임처럼 진입 흐름과 준비 공간을 제공한다.
* 구현/기획 범위: 오프닝 화면, 로비 화면, 코어 선택, 영구 강화, 일일 보급, 광고 보상 6종 진입점, 도감/상점/설정 진입 자리, 정화 런 시작.
* 산출물: `scripts/Game.gd`의 `ScreenState.OPENING`, `ScreenState.LOBBY`, `ScreenState.RUN` 상태 전환.
* 발견된 문제: 기존 빌드는 실행 즉시 런이 시작되어 코어 선택, 영구 성장, 광고/IAP 진입점, 재도전 준비 흐름을 담기 어려웠다.
* 수정 지시: 단일 `Main` 씬은 유지하되 UI 상태를 분리하고, 전투 노드는 런 시작 시 생성하고 로비 복귀 시 정리한다.
* 성공 기준: 앱 실행 시 오프닝이 보이고, 시작하기를 누르면 로비로 이동하며, 로비에서 코어 선택/강화/보급/광고 보상 후 정화 런을 시작할 수 있다.
* 검증 방법: Web 빌드에서 오프닝 버튼, 로비 버튼, 코어 선택, 일일 보급, 영구 강화, 광고 보상 fallback, 런 시작을 클릭해 화면 전환과 한글 표시를 확인한다. Android Debug APK에서는 테스트 광고 로드와 보상 지급을 실기기에서 확인한다.
* 승인 상태: Approved

## 로비에서 할 일

| 영역 | 기능 | 출시 연결 |
|---|---|---|
| 코어 선택 | 정화형/공격형/흡수형 중 하나 선택 | 빌드 다양성과 코어 스킨/IAP 확장 |
| 스테이지 정보 | 현재 스테이지, 목표, 보스, 추천 전투력 표시 | 스테이지 3개 확장 |
| 영구 강화 | 코어 출력, 흡수 반경, 시작 체력 강화 | 런 종료 후 반복 성장 |
| 일일 보급 | 정화 코어 파편 보상 | 보상형 광고/일일 리텐션 연결 |
| 광고 보상 | 추가 보너스, 무료 상자, 드론 체험 | AdMob 보상형 광고 연결 |
| 무기 도감 | 무기/진화 조합 안내 진입점 | 진화 발견 재미 강화 |
| 드론 | 드론 해금/장착 화면 진입점 | 드론 패키지/IAP 연결 |
| 상점 | 광고 제거, 스타터 팩, 스킨 팩 진입점 | Google Play Billing 연결 |
| 설정 | 사운드, 진동, 언어, 데이터 관리 진입점 | 출시 안정성/접근성 |
| 정화 런 시작 | 선택한 코어와 영구 강화 적용 후 런 시작 | 핵심 게임 루프 진입 |

## 현재 구현 범위

- 실제 동작: 오프닝, 로비, 코어 선택, 일일 보급 1회, 영구 강화 3종, 보상형 광고 6종 진입점, 정화 런 시작, 결과 후 로비/재도전.
- 자리만 확보: 무기 도감, 드론, 상점, 설정. 세부 화면은 다음 단계에서 구현한다.
- SDK 연결: Android Gradle 빌드에는 AdMob Rewarded SDK와 `CoreSurvivorAdMob` 플러그인을 연결했다. Web/Editor에서는 광고 미지원 안내만 표시한다.
- 저장 제외: 현재 로비 재화와 강화는 메모리 상태다. 다음 단계에서 `SaveManager`로 JSON 저장을 연결한다.

## 화면 기준

- 기준 해상도는 Android portrait `720x1280`이다.
- 브라우저 preview는 실제 Android 비율을 확인하기 위해 `tools/patch_web_export.ps1`에서 Web canvas를 9:16 세로 화면으로 중앙 정렬한다.
- 로비 UI는 작은 모바일 화면에서 터치 가능한 크기를 우선하고, 영구 강화 버튼은 겹침을 막기 위해 세로 3단으로 배치한다.
- 데스크톱 브라우저의 남는 좌우 공간은 게임 영역이 아니며, Android 기기에서는 세로 화면 기준으로 플레이한다.

## 다음 개발 순서

1. 로비 상태 저장: 재화, 영구 강화, 선택 코어, 일일 보급 수령 상태.
2. 무기 도감 화면: 8무기와 6진화 조합 표시.
3. 드론 화면: 6드론 해금/장착/강화.
4. 상점 화면: 광고 제거, 스타터 팩, 스킨 팩, 파편 팩 UI.
5. 설정 화면: 사운드/진동/언어/데이터 초기화.
